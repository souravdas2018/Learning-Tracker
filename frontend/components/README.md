# Components

Purpose: Reusable presentational and layout components used across pages.

Examples:
- `Layout.tsx` — top-level layout and navigation
- `ProgressBar.tsx` — reusable gradient progress bar used on module pages

Guidelines:
- Keep components small and focused
- Prefer props over context unless state is truly application-scoped

Testing and storybook:
- Consider adding small unit tests for pure components and Storybook for visual review.
